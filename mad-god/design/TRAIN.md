# 神也疯狂 · 训练排队（开天辟地）

Jerry 放行。这一刀只修训练：选中的勇士去**指定训练营贴墙排队**，站住等训，营顶挂**己方**进度。不打、不法、不补神迹特效。

参照《开天辟地》：征召 = 把勇士送进营，进门一个一个训，不是点一下变兵，也不是全员挤进中心乱跑。

鼠标仍走 `INTERACT.md`：先选人，再点训练图标。没选人「先选人」，没营「先盖训练营」。

## 点训练之后

1. 只派**选中的** `walker`。圈外的人继续砍树，禁止全员停工。
2. 送到己方已建成的对应营（`warriorHut` / `temple` / `fireHut` / `spyHut`）。多座同种营：去**最近的一座**，整队去同一座，不要拆开。
3. 每人 `job = train`，`targetId = 那座营`。此后禁止 `wander`、禁止再派去砍树、禁止 `repath` 到营中心乱绕。到点就清 path，站住。

## 排队（贴墙绕圈，不要门口拉长队）

对照《开天辟地》：人围着训练营的墙站，不是从门口往外扯一条直线。门口直线槽会把后排越排越远，路也越绕越长。作废。

槽位贴垫子外沿走一圈，间距约 0.7：

| 槽 | 谁 |
|---|---|
| 0 | 正在训的人，站在门边（可贴门，不要拉到远处） |
| 1、2、3… | 从门边开始，沿墙逆时针（或顺时针，定一边）贴外沿占槽 |

- 人绕着四面墙站，像围着房子，不要垂直门口往外延伸。人多了就拐弯贴下一面墙。
- 同时只训 **1** 人，约 4 秒。训完从门边出来变成对应兵种，下一号立刻补进槽 0，后面的人沿墙往前挪一格。
- 排队的人面向墙/门，站住。碰撞不要把他们挤出槽。
- 没到槽的人沿路走向**自己的墙边槽**，不要全员追营中心，也不要在门口堵成一条长蛇。
- 取消：右键取消选择不影响已在队里的人；另下谕令（定居/聚集）才能离队。

## 营顶进度（只给己方）

己方（玩家，蓝方）训练营头顶挂一块小进度牌：

- 无人在训：不显示。
- 有人在训：一条横条，按当前槽 0 的 `channel / 4s` 从空到满。颜色用己方色。
- 可选：条旁一个小数，等于队里人数（含正在训的）。不要写字说明书。
- **敌方营不要挂牌。** 玩家只看自己的人。

用简单 3D 条或屏幕 billboard 即可，不要粒子、不要贴图。

## 不要做

- 不要即时变身。
- 不要全图抓人。
- 不要开战、不法、不补神迹特效。
- 不要热键。不要默认左键抬地。
- 不要把人放大。不要上贴图。

## 验收（各拍一张，随手传到设计师）

1. 框 4～6 名勇士，点训练武士：人**贴着营墙绕开**，不要门口拉成一条长队；圈外树边继续砍；士兵仍是 0。
2. 等几秒：人仍贴墙，不散、不往门口外扯。营顶进度条在涨。
3. 第一个人出来变成武士，士兵 1；条子清空再给下一个人涨；墙边的人往门挪一格，不是从远处新抓。
