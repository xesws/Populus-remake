# 神也疯狂 · Object 重构稿

Jerry 判定：当前底座是《我的世界》柱体，不是神游戏的地面。
建造 / 战斗 / 魔法 / 交互全部冻结。先把 `Terrain`、`Unit`、`Building` 三个 Class 拆掉重做。
做完这三个，才有资格回头谈系统。

单位编制看 `CLASSIC.md`（《开天辟地》：祭司 / 勇士 / 武士 / 传教士 / 火战士 / 间谍 / 野人）。外形看 `SPEC.md`。这份锁 Object。

## 错在哪（对着现码）

| 现在 | 文件 | 为什么错 |
|---|---|---|
| `SIZE=52`，`h: Uint8Array`，`setHeight` 做 `v \| 0`，`MAX_H=8` | `world.ts` | 整型台阶。山是一格一根柱子。 |
| `InstancedMesh(BoxGeometry(1,1,1), 52×52)` | `render.ts` | 渲染就是 Minecraft。没有坡，只有方块。 |
| `Building = {x, z, level}`，无 `yaw` | `types.ts` | 房子只能正南正北，占地只能 3×5×7 正方形。 |
| `flatSize` 要求奇数正方形整格等高 | `world.ts` | 地形被逼成围棋棋盘。 |
| `Unit.path: Cell[]`，贴格子中心走 | `sim.ts` / `path.ts` | 人是棋子，不是走在地面上的身体。 |
| 火山：瞬间改 5×5 整格 + `lava[]` 计时 | `spells.ts` | 16 个格子铺一团火。 |
| 地震：半径 3 整格 ±1 | `spells.ts` | 人卡在格缝里。既不平滑也不丝滑。 |

人已经是半格（~0.5）。地还是 1.0 整格。分辨率对不上，后面所有神迹都只能「改几个大方块」。

## 对的模型

地是一张**连续高度场**（heightfield），不是体素。
每个采样点一个浮点高度，渲染成三角网。人走在双线性插值表面上。
房子坐在一块铲平的垫子上，垫子可以转向。
神迹是随时间雕塑这张网，不是给 16 个格子赋值。

这是 Populous 的地面，不是 Minecraft。

## 这一刀只做三件事

1. `Terrain`：高分辨率浮点高度场 + 三角网。
2. `Unit`：连续身体，有朝向，Y 贴地。
3. `Building`：带 `yaw` 的占地，mesh 跟着转。

生产、战斗、五种神迹的规则和特效**不要在这刀里重做**。
`raise` / `lower` 改成笔刷雕塑，好验收地面。其它法术暂时坏掉或空操作都可以。

## Terrain

世界范围仍是 52×52（岛一样大）。采样乘 4。

```
WORLD     = 52
RES       = 4
STEP      = 0.25          // 人占约 2 个采样，1/4 旧格 = 1 个采样
SAMPLES   = 209           // 52/0.25 + 1，含两边
MAX_H     = 8             // 仍是世界高度上限，但是 float
WATER     = 0.20
MAX_SLOPE = 0.70          // 超过就走不动（约 35°）
```

`h` 改 `Float32Array(SAMPLES * SAMPLES)`。禁止 `| 0`。

同分辨率的层：

- `lava`：熔岩量（float，可流动）
- `scorch`：焦土（float，盖过的地）
- `swamp`：沼泽
- 占用不再按整格 `occ[]` 钉死，改查询 Unit 圆 / Building OBB

### 必须暴露的 API

```
heightAt(x, z)            // 双线性，世界坐标
normalAt(x, z)
slopeAt(x, z)
sculpt(x, z, radius, dh)  // 每帧可调。软笔刷，边缘 falloff
flattenPad(cx, cz, w, d, yaw, h)
walkableAt(x, z)          // h > WATER 且 slope < MAX_SLOPE，且不在房垫里
inMap(x, z)               // 世界坐标 0..WORLD
```

`sculpt` 是抬/降的唯一入口。半径约 1.2–1.6，中心强、边缘弱。一帧只改一点点，靠连续施法堆出山。
不要再提供 `raise(ix, iz)` 这种整格 +1。

`flattenPad` 把旋转矩形下的采样铲到同一高度。给房子用。矩形可以斜着。

岩浆流动、焦土扩散这一刀**只留字段和每帧衰减/沿梯度流动的空位**，不要做喷发演出。

### 生成

岛的轮廓可以沿用现在的径向海岸，但高度用连续噪声，禁止 `stampPlateau` 盖 3×3 整平台。
开局两队各留一块已铲平的小垫（约 3.2×3.2，可微旋），让人有地方站。其余全是坡。

### 渲染

- **一张** `PlaneGeometry(WORLD, WORLD, SAMPLES-1, SAMPLES-1)`，顶点 Y = 高度。
- 顶点色按高度走现有色板（草 / 赭 / 岩 / 雪），焦土、熔岩改顶点色。
- **丢掉** `InstancedMesh` 柱体。不要用方块柱子「假装」高度场。
- 水面仍是平面。
- 光标是贴地的小环，不是 1×1 扁盒子。
- 脏矩形只更新那一块顶点，不要每帧重建整张岛。
- 目标 60fps。800×600 点绘风格可以留，那是滤镜，不是世界。

## Unit

人是贴在地面上的刚体，不是格子里的棋子。

```
id, team, kind
x, z              // 连续世界坐标
y                 // 每帧 = heightAt(x, z)
yaw               // 朝向，移动方向带过来
radius            // walker 0.22 / shaman 0.24 / warrior 0.25 / preacher 0.24 / firewarrior 0.25 / spy 0.22 / wildman 0.22
```

`path` 如果还要，改成世界坐标路点，**禁止**再吸附到整数格中心。
寻路可以在 `STEP` 或 0.5 的采样上做，但移动是路点之间插值。
斜向走、沿坡走，Y 跟着地面，不许一格一跳。

碰撞：圆 vs 圆，圆 vs 房子 OBB。把人从体积里推出去。出生点在垫子外沿。

外形仍按 `SPEC.md` / `SCALE.md` 的盒子尺寸，**不要再放大人**。
`kind` 留 shaman / walker / warrior / preacher / firewarrior / spy / wildman。传教士、火战士、间谍不能删。血量字段先留着。不要在这刀重写战斗。

## Building

房子是带朝向的物体，不是盖在棋盘上的图章。

```
id, team, level
x, z, y           // y = 垫子高度
yaw               // 至少四向 0 / 90 / 180 / 270，八向更好
padW, padD        // 世界单位，随等级
hp, prod          // 先留
```

| 级 | 墙 XZ | 垫子 | 视觉高度 |
|---|---|---|---|
| L1 | 2.2 | 2.6 × 2.6 | ~1.1 |
| L2 | 3.8 | 4.4 × 4.4 | ~1.8 |
| L3 | 5.6 | 6.4 × 6.4 | ~2.6 |

垫子是**旋转矩形**，不要求边平行于世界轴，不要求边长是奇数格。
占地、寻路阻挡、出生外圈，全部用这个 OBB，禁止再写 `r=1/2/3` 的整格戳印。

等级看垫子底下高度方差和面积，不看 `flatSize(3/5/7)`。
`canFound`：垫子全是陆地、坡够平、不和其他垫重叠。

定居时 `yaw` 取 walker 当时朝向（收到四向）。mesh `rotation.y = yaw`。
屋顶 XZ 仍不得大于墙（`COLLISION.md` 这条留着）。

## 验收（三张图，缺一张都不算过）

1. **山**：绕岛看，山是坡，不是楼梯方块。近距能看出 0.25 的采样，远距是连续地面。
2. **人**：斜着走、上山下，脚贴插值表面，不跳格，不卡在「格缝」里。
3. **房**：至少能盖出斜 45° 或 90° 的一座。垫子跟着转，人绕 OBB 走，不穿墙。

抬地是软笔刷，按住时地面按帧隆起，不是突然冒出一根柱子。

过这三张之前，不许回头做建造系统、战斗系统、魔法系统、交互系统。

## v0.13 地图丝滑度（生成与编辑规则更新）

- 生成期：高度场先经 **3 轮盒式松弛**（水面以下样本不动）；knoll 鼓包用 smoothstep(0,1,·) 替代旧 max(0,·) 尖点；山脊凸包后再松弛 2 轮。
- 浅水滩涂：紧邻陆地的水域抬到 0.16（仍低于 WATER，可通行性不变），海岸线从断崖变缓滩。
- 出生平台高度随当地地形（max(当地, 0.8) + 0.25），不再固定 2.05（原值会在海岸边造出两米海崖）。
- 编辑期 `sculpt` / `sinkTrench`：falloff 改 **smoothstep**（C1 连续，笔刷边缘无唇沿）。
- `flattenPad`：内部保持精确平整（地基要求不变），外圈 0.45~2.0 带 smoothstep 缓坡 + 1 轮局部松弛——房屋周围不再断崖。
- 移动：坡度惩罚曲线调缓（min(slope,1.5)×1.4）、速度下限 0.22 → 0.5；单位高度指数趋近地形（离地钳制 0.02，防误判腾空）。
- 寻路：爬坡成本 climb×1.15+slope×1.25 → climb×0.6+slope×0.7，路径更直、撞 maxVisit 更少、卡死脱困触发率大降。
