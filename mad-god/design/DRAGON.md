# 神也疯狂 · 大龙（飞龙）

参照《开天辟地》的飞龙印象：飞在半空的机械怪，一对小翅膀，贴盒子低多边形、不贴图。
稿 `DRAGON.md`。选人/右键口径照 `INTERACT.md`，数值集中在 `types.ts` 的 v0.30 常量区。

一句话：20 个牛战士进厂炼出一条龙，龙替你烧穿对面。

## 数值（全部在 `types.ts`，改参不动逻辑）

| 项 | 值 | 备注 |
|---|---|---|
| 血量 | 600 | = 100 × 村民 6 血 |
| 飞行速度 | 1.5 | 村民 2.4，"偏慢" |
| 攻击范围 | 10 | = 索敌半径 = 脱锁距离 |
| 攻击间隔 | 2.4s | 吐息 |
| 巡航高度 | 地表 + 2.2 | 贴地表上空 |
| 护甲 | 2 | 龙鳞（火战士 5 攻 → 3/发） |
| 生产 | 60s | 20 名牛战士进驻满后开始 |
| 工厂 | 3.2×3.2 占地 / 6 木 | 大龙训练营（外观类似工厂） |

## 生产链路（大龙训练营）

1. 点建筑图标「大龙训练营」（6 木），选勇士落地、送木起升（同哨塔/营地流程）。
2. 选中牛战士（火战士）**右键自家工厂** → 走到门口自动进驻（homeId 挂厂、隐藏、不可点选、不可被攻击）。
3. 厂顶**进驻条**（20 格刻度）随进驻人数填满；满 20 后其下出现**生产条**，60s 走完。
4. 完成：20 名进驻者移除（化作大龙），**大龙在工厂上空空降**（从高处下坠到巡航高度）。
5. 生产途中工厂被拆：20 名牛战士原样弹出存活（同哨塔弹出），进度作废；满员后厂内锁定，第 21 名进不去。

## 大龙行为（DragonSystem 独占，OOP 单点归属）

- **飞行**：不走 A*、不受地面碰撞/卡死看门狗；攻击时逼近到目标旁 8 格并环绕悬停；有飞行令直飞；无事绕团队锚点（篝火/磁铁点）盘旋。
- **高度**：贴"地表 + 2.2"巡航；巡航基准取 `max(地表, WATER)` 兜底（当前世界生成与 sculpt 对高度场有 ≥0 钳制、海床最低 ≈0.04，"沉水下"不可达——此兜底是防御性的，未来地形放开负高度仍安全）。空降从 +6 高处按 3/s 下坠到巡航线。
- **视觉火焰**：fireT 的衰减在地面 moveUnits 里，飞行单位被跳过——DragonSystem 每帧补递减，被闪电/火球点燃的火焰按时熄灭（v0.30 自查修复）。
- **全自动索敌**：每 0.4s 一轮，10 格内**随机**挑一个敌方地面单位或建筑。
- **脱锁**：目标跑出 10 格 → 立即放弃并重选（玩家手动指定的目标同样适用）。
- **手动**：选中大龙右键敌人 = 指定攻击目标（手动可指敌方大龙，龙对龙互喷）；右键空地 = 直飞该点。
- **吐息**：龙口发射追踪弹（9 格/s），落地生成**燃烧地块**：持续 4.5s、每秒伤害随剩余寿命线性衰减（起始 8/s，不经过护甲），对压到的敌方建筑走骨架三段；点名目标另吃 2 点直接伤害。
- **生产冻结**：`freezeProd`（导演摆拍）期间工厂停产，与茅屋 produce() 同规。

## 受击与克制

- **魔法必中**：闪电（-8）、天降火球/陨石（点燃）、击飞气浪（-6）都命中大龙，但**只掉血**，无击飞/倒地物理。
- **地面持续型不波及**：沼泽、地裂缝、龙卷风、岩浆池、水面都在地面——大龙飞在上面，一律免疫（自己的吐息火 patch 同样烧不到飞行单位）。
- **对空克制**：地面牛战士与哨塔可锁大龙并射击，弹道瞄准龙身实际高度、无视地形遮挡；中弹只掉血（经护甲），不被击退。
- **近战打不到**：武士锁不到大龙（够不着，不站桩仰望）。
- **不 converter**：传教士感化、转化术对大龙无效。
- 厂内进驻者：不可点选、不可被攻击、不被地面火海波及（工厂本体承伤）。

## 光标选中（本刀重点：半空单位误选问题）

问题：大龙悬在半空，旧拾取按"单位锚点屏幕距离 28px"取最近——光标指在龙身上时，龙体**身后**的地面单位反而更近，造成误选。

方案：**剪影拾取 + 绝对优先**（`picking.ts` 纯函数 + `game.ts` 投影）：

1. 沿龙体脊线取 5 个世界坐标采样点（尾→头，高度 y+0.55），命中半径 0.85。
2. 每点用 `worldToCanvas` 投影成屏幕圆，屏幕半径按"沿相机右向偏移 0.85"的像素距 ×1.15 容差。
3. `pickDragonAt`：光标落在任一采样圆内即命中，多龙取中心最近者。
4. `closestBlue / closestRed` **先跑剪影**，命中直接返回大龙，跳过全部地面单位判定；剪影外走原判定（零回归）。敌方大龙同样生效 → 拳头光标 + 右键指定攻击。
5. 反馈：选中环画在**龙体正下方地面**（影环，×2.2 尺度）；框选按投影中心判定；提示「选中大龙」。

## 实现落点（OOP 拆分）

| 文件 | 职责 |
|---|---|
| `entities/units/dragon.ts` | `Dragon extends Unit`，`isFlying()=true`（零新增字段） |
| `entities/buildings/dragon-factory.ts` | `DragonFactory extends Building`（dwell=进驻数、prod=生产进度） |
| `entities/fire-patch.ts` | `FirePatch`：燃烧地块（衰减 DoT） |
| `systems/dragon-system.ts` | 大龙与工厂的唯一归属：飞行/索敌/吐息/火 patch/进驻生产 |
| `picking.ts` | 剪影拾取纯函数（headless 可测） |
| `render-parts/dragon-fx.ts` | 吐息弹体 + 燃烧地块渲染 |

地面系统只经 `Unit.isFlying()` 一个门控跳过飞行单位（寻路/碰撞/卡死/索敌/危害/甩人）。

## 红方 AI

本刀不接：AI 不主动建厂出龙（后续刀接 war-director）；红方牛战士/哨塔会自动反击蓝方大龙，机制两队通用。

## 验收（dragon-check 全绿 + 手测）

1. 建厂 → 20 牛战士进驻满 → 生产条走 60s → 大龙空降，进驻者消失。
2. 大龙自动烧 10 格内目标；目标跑出 10 格换目标。
3. 闪电/陨石/击飞命中大龙只掉血；沼泽/龙卷风不波及。
4. 牛战士对空射中大龙；武士锁不到。
5. 光标点龙身 = 选中大龙（不误选身后单位）；光标在剪影外照常选地面单位。
