# 神也疯狂 · 右键走 + 开战

Jerry 开口。人物房屋三刀过了。这一刀只做两件事：右键走路，对准敌人出拳头再打 / 拆。

参照《帝国时代》和《开天辟地》：选人、右键点地走，右键点敌人打。魔法冻着，不要改已过的神迹。

鼠标总规以这份和 `INTERACT.md` 为准，盖过 `HOUSE.md` 里旧的左键走路。

## 当前：右键走 + 拳头

### 走路

- 先选中（点或框）。**右键点空地**：点上冒一个低多边形前往标记（旗 / 金环即可），只有圈里的人走过去，保持选中。
- 圈外继续原来的活。
- 再**左键点空地**：取消选择，环没了。人继续走到刚才那个点。
- 没选人：左键空地、右键空地都不要抬地，也不要走路。
- 有建造预览或神迹工具时：右键只取消工具，不要走路。

### 拳头光标

- 有选中，鼠标停在**敌方单位或敌方建筑**上：光标换成一个 3D 拳头（低多边形，不要贴图）。
- 停在空地：不要拳头，右键出前往标记。
- 停在己方、野人、未建成垫：不要拳头。
- 没选人：不要拳头。

### 打人

- 有选中，右键点敌方单位：圈里的人走过去近战打。这一刀所有兵种都是走近了打（祭司、勇士、武士、传教士、火战士、间谍同一套近战）。
- 不要火球、不要传教、不要间谍放火。那是后面的刀。
- 没下命令不要自己找人打。
- 打到人倒地消失即可。不要做完整克制表。

### 拆屋

- 有选中，右键点敌方已建成建筑：圈里的人走过去拆。
- 房子血量沿用已过的骨架：完好 → 柱梁骨架（屋宇还算）→ 再拆没（屋宇 -1）。
- 不要一次锤没。要看得出在拆。
- 右键点己方屋：入住（不要拆自己）。右键点己方训练营：去排队。右键点己方未完成垫：去盖。

### 验收图

场上要有至少一个敌方勇士、一座敌方茅屋（红方即可）。各拍一张，传到设计师。

1. 选一个勇士，右键点空地：地上有前往标记，人在走，脚下环还在。
2. 人还在走时左键点空地：环没了，人继续走到刚才那个点。
3. 选人，鼠标停在敌方勇士上能看见 3D 拳头；右键后己方走过去打，敌人倒下。
4. 选人，鼠标停在敌方茅屋上是拳头；右键后走过去拆，房子变成骨架或没了，不要一次跳没又不留骨架。

### 不要做（这一刀）

- 不要改已过的神迹，不要点法术栏。
- 不要火球 / 传教 / 间谍放火。
- 不要自动开战、不要做谕令「战斗」AI。
- 不要堆木头跳 L3。
- 不要热键。不要默认左键抬地。
- 不要上贴图，不要把人放大。

## v0.7 起：战斗数值体系（盖过上面「不要克制表」旧规）

上一刀的拳头是占位：所有兵种同样的 2.2/秒连续掉血。v0.7 起底层有完整的血量与伤害判定：

- 每个兵种有 攻击 / 护甲 / 攻击间隔 / 射程 / 索敌半径 数值，集中在 `src/game/types.ts`（`UNIT_ATTACK` 等表）。
- 单发伤害 = `max(1, round(攻击 × 克制系数 − 受击护甲))`；克制系数查 `COUNTER_MULT`（缺省 1）。
- 攻击按间隔出刀（`atkCd` 冷却门控），不再无间隔连续掉血。
- 兵种差异（str = 1）：
  - 武士：攻 6 / 甲 2 / 1.1s —— 两刀解决火战士（9 血），一刀带走村民（6 血）。
  - 火战士：攻 5 / 1.8s —— 克制村民（×1.2，一刀 6 血）。远程火球 v0.9 接入。
  - 传教士：攻 3 / 甲 1 / 1.3s；间谍：攻 3 / 1.0s；萨满：攻 3 / 1.5s；村民与野人：攻 2。
- 拆屋伤害 = 攻击 × 0.6（武士 4/刀），骨架三段规则不变。
- 伤害统一走 `src/game/damage.ts`（`applyUnitDamage` / `applyBuildingDamage`），近战 / 火球 / 落地伤害共用一套护甲与克制。

## v0.8 起：自动索敌与还手

v0.7 的拳头是「有命令才打」。v0.8 起底层补上对称的进攻 / 防守本能，AI 端零改动：

- 武士 / 传教士 / 火战士在 `UNIT_SIGHT` 半径内自动攻击最近敌方单位（屋内或死亡单位不算）；村民 / 萨满 / 间谍 / 野人 `UNIT_SIGHT = 0`，不主动索敌。
- 任何单位被敌对阵营打到、且当前无目标、未在移动令 / 训练态时，立刻还手并把攻击者锁为 atkId。
- 自动获得的目标追出锚点 `AGRO_LEASH = 8` 格即放弃；玩家手动指令 (`agroX = -1`) 不受拴绳限制。
- 红方 fight 谕令下的士兵经同一套对称索敌真正开战，不再依赖额外 AI。
- 挂接位置：`CombatSystem.combat()` 内负责拴绳检查与还手触发，`Sim.repath()` 内 NEUTRAL / armageddon 分支之前调用 `acquireTarget`，让空闲单位每帧都有机会重新找人。

## v0.9 起：火战士远程火球

火战士从近战占位升级为真正的远程兵种（对单位与建筑都生效）：

- 射程 4.5 格（`UNIT_RANGE`）：目标进射程、且 `world.losBlocked` 判定视线通畅才发射；被地形遮挡视为未进射程，继续贴近找射界。
- 弹道：平飞高度 = 两端地形较高者 + 0.6，弹速 4 格/秒（`FIREBALL_SPEED`）；飞行途中地形被抬过弹道线，火球撞地熄灭（发射端 LOS + 飞行撞地双保险）。
- 命中概率（`Math.random`）：40% 仅伤害 / 40% 击退（沿弹向推 1.2 格）/ 20% 原地击飞（垂直速度 5.2，落地时结算 2 点经护甲的落地伤害 `flyDmg`）。
- 伤害走统一入口 `applyUnitDamage`（含护甲与克制）；对建筑 `攻击 × 0.6` 走骨架三段。
- 腾空中的单位（被击飞/法术掀飞）既不能出刀、也不会被近战或水平火球命中，落地即恢复。
- 渲染：火球方块按 `Projectile.y` 弹道高度飞行（`render.ts syncShots`）。
