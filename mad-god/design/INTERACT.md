# 神也疯狂 · 鼠标交互（开天辟地）

对照《帝国时代》和《上帝也疯狂 3》。
**除了方向键移镜头，所有键盘绑定都取消。** 数字选神迹、ZXCV 谕令、TYGH 征召、Alt 点选、空格暂停，全部拆掉。操作=先点图标，再左键。
默认左键不是抬地。

## 默认（没选工具）

Jerry 2026-08-27 改口，按《帝国时代》右键走。旧的「左键点地走、右键取消选择」作废。开战细节见 `COMBAT.md`。

- 左键点己方人：选中。拖框：框里己方都选上。
- **左键点空地或己方屋/营：取消选择。** 已经在走 / 在打 / 在住的人继续干。不要抬地。
- **有选中时右键点空地：走到该点，保持选中。** 地上出短时 3D 前往标记。只有圈里的人走。
- 有选中时右键点己方已建成茅屋：入住。右键点己方已建成训练营：去那一座排队。右键点己方未完成垫：去盖。
- 没选中时右键点空地：什么都不做。
- 有选中时右键点敌方单位：进攻。右键点敌方建筑：拆屋。
- 有选中且光标在敌人 / 敌屋上：3D 拳头。空地不要拳头。
- 有预览或神迹工具时：左键落地照旧，**右键取消工具 / 预览**，不走路、不取消选中的人。
- 选中的人脚下有环。

## 建造（先点图标，再落地）

1. 点界面上的建筑图标（茅屋 / 武士营 / 神庙 / 火战士营 / 间谍营）。
2. 鼠标下出现这座建筑的 **3D 半透明预览**，跟着走，能看出占地和朝向。
3. 地不合法（水里、太陡、叠别人垫）预览变红，左键无效。软笔刷铺平后应能盖。`padReady` 只许微调：land ≥ 0.80、variance < 0.22、maxSlope < 0.70。水里和叠垫继续否。不要砍掉判定。
4. 必须先选中至少 1 名勇士，再点图标、再落地。没选勇士：提示「先选人」，不要开工。
5. 左键点合法地面：定下地皮，**只有选中的勇士**去盖。不许全图抓人。预览可以接着盖下一座，直到右键取消。
6. 滚轮转 yaw。不要用键盘转。

盖房 = 先选勇士 → 点图标 → 预览 → 左键落地。不要自动抓全图的人。点地走路、入住见 `HOUSE.md`。

## 训练

1. 先选中勇士（点或框）。
2. 再点训练图标（武士 / 传教士 / 火战士 / 间谍），**或左键点己方已建成的对应训练营**。图标仍按 `TRAIN.md` 去最近的一座；点营则去**那一座**排队。
3. 没选人：提示「先选人」。没营：提示「先盖训练营」，不要全员跑去盖。点营但选中的不是勇士：提示「选勇士去训练」。未建成的垫（level 0）不训练。
4. 只有选中的勇士走到对应营门口贴墙排队站住，圈外的人保持原状态（v0.10 起未被指派的空闲村民原地站立）。同时只训 1 人。营顶挂己方进度。见 `TRAIN.md`。

## 神迹和抬地

- 抬 / 降、闪电、地震……先点图标，**再**左键点地图。
- 没点抬地图标时，左键绝不改地形。
- 抬 / 降按住左键拖 = 软笔刷。点一下人仍优先选人。

## 谕令

先选人，再点谕令图标（定居只留给「去砍树/空闲」；聚集要再左键点一个地点放磁铁；战斗；到祭司）。
没选人点谕令：提示「先选人」。

## 待机（v0.10 起）

- 蓝方单位无指令原地站立：不漫游、不自动找活。详细规则见 `COMBAT.md` 的 v0.10 一节。
- 站立不影响战斗本能：索敌半径内敌人照样自动攻击、被打照样还手。
- 要村民帮忙盖房：右键点未建成工地指派（`assignBuilders`）；被指派者自动砍树运木直到建成。
