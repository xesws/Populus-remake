# 神也疯狂 · 人物、地图、房屋

人物房屋三刀过了。走路已改成右键，开战见 `COMBAT.md`。这一章旧验收还在，点地操作以 `INTERACT.md` 为准。

参照《开天辟地》：人选人、点地走、派人去盖、派人住进茅屋，屋里慢慢出人，人多了房子才从 1 升到 2、3。不是自动堆木头跳到大屋。

鼠标总规仍看 `INTERACT.md`。训练仍看 `TRAIN.md`。木头砍树仍看 `PRODUCTION.md`，升级规则以这份为准。

## 顺序（不许跳）

1. **选中点地走** 过了。
2. **寻路不卡** 过了。
3. **住人升屋** 过了。
4. 走路 / 开战改口见 `COMBAT.md`。

## 已过：选中点地走

现在的病：选中祭司或勇士之后，点地是取消选择，人不受控。盖房、入住、训练都走不到。

### 点地

> 当时验收是左键走、右键取消。Jerry 已改口：右键走、左键空地取消。以 `INTERACT.md` + `COMBAT.md` 为准。

- 有选中：**右键点空地 = 走到该点**，保持选中，地上出前往标记。只有圈里的人走。
- **左键点空地**才取消选择。已经在走的人继续走。
- 没选中：左键点空地不要抬地。
- 有工具 / 预览时，右键仍取消工具。
- 选中的人脚下仍有环。走的时候环跟着。

### 去盖房

- 先选中至少 1 名 `walker`，再点茅屋（或训练营）图标，预览落地。
- 只有选中的勇士走向那块垫子去盖。不许全图抓最近的人。
- 没选勇士就点建造：提示「先选人」，不要开工。
- 祭司、武士、传教士、火战士、间谍不能去盖。选中他们点建造：提示「选勇士去盖」。

### 去入住 / 去训练

这一刀先能把人选到门口。真正住进去、真正进营变兵，后面的刀再收。

- 入住：选中勇士，再左键点己方已建成的茅屋 → 他们走向那座屋的门边。这一刀走到门边站住即可，先不要进屋里产人。
- 训练：仍按 `TRAIN.md`（先选人，再点训练图标）。这一刀不要改排队。

### 不要做（这一刀）

- 不要自动升到 2 / 3。不要改产人。
- 不要重写整张寻路。平地上点过去必须到；卡住的完整修法下一刀。
- 不要开战、不要做法术、不要上贴图、不要把人放大。

### 验收（各拍一张，传到设计师）

1. 点一个勇士，再左键点一块空地：只有他走过去，脚下环还在，别的人不动。
2. 框 3 个勇士点地：三个一起走；圈外树边继续砍。
3. 点祭司点地：祭司走到该点。右键后环没了，人继续走到刚才那个点。
4. 先选 2 个勇士，再放一座茅屋预览落地：只有这两人去垫子边，不是全图的人都跑去。

## 已过：寻路不卡

现在的病：人常在路上冻住，尤其是去盖房的时候钻进垫子或贴着墙走不动。

### 垫子和房子

- 已建成的房子、未完成的垫子，**内部不能走人**。从门边绕，不要穿模。
- 门前留一条能走近的缝（大约一人宽）。预览落地时也要留这条缝，不要把唯一的路封死。
- 去盖房的人站在**垫子外沿**干活，面向垫子。不要走进垫子中心、不要嵌进柱子里。

### 卡住就要绕

- 有目标却差不多 1 秒没挪地方：丢掉当前路，绕开挡路的房 / 树 / 人再走。不要一直原地抖。
- 点地穿过房子或树丛：必须绕到点，不许在障碍中间停死。
- 砍树的人站在树外沿，不要钻进树干冻住。
- 出生、卸木头都在外沿，不穿墙。

### 不要做（这一刀）

- 不要住人、不要产人、不要升 2 / 3。
- 不要开战、不要做法术。
- 不要重做选中点地走（已过）。
- 不要上贴图、不要把人放大。

### 验收（各拍一张，传到设计师）

1. 选一个勇士，点地让他绕过一座已建成的茅屋走到对面：人从旁边绕过去，没有贴墙冻死。
2. 选两个勇士放一座新茅屋：两人站在垫子**外沿**，没有钻进垫子里卡住。
3. 点地穿过几棵树：人绕树走到点，没有在树中间停死。

## 已过：住人升屋

现在的病：空屋自己吐人，木头一堆就跳到 3 级。Jerry 要的是：选中村民走进去住，才慢慢产人；产到数量才升 2、升 3；屋顶有图标显示产速。

### 空屋

- 木头只盖出空的 L1。空屋**不产人、不升级**。
- 空屋顶上没有产速图标。
- 堆木头不得跳级。已建成的屋不要再收木头去升级。

### 入住

- 先选中至少 1 名 `walker`，再左键点己方已建成的茅屋。
- 只有选中的勇士走向那座屋的**门边**，走进去住下（人进门后可以藏在屋里，门口不必再站一排）。
- 点到屋：提示「前往入住」。人先沿门缝走进去（约 0.4 秒，看得见），再藏进屋里，提示「勇士住进茅屋（住/上限）」。
- 屋顶门侧挂入住牌子：空槽深色块，住着的人用队色身子 + 肤色头。空屋不挂；人满牌子仍在（产速图标人满才藏）。己方、敌方屋都挂。
- 没选人点屋：不要自动抓人入住。
- 祭司、武士、传教士、火战士、间谍不能住茅屋。
- 右键取消选择不影响已经住进去的人。

### 产人

- 屋里有人，才开始慢慢产人。进度满了，门口走出一个新勇士。
- L1 大约 10 秒一个；人多或升到 2 / 3 可以略快。人满（L1=2，L2=5，L3=8，全队占帽）停产。
- 新勇士出在门边外沿，不穿墙。

### 升级

- 这座屋自己产到 2 个（含住着的）→ 变成 L2 中屋。
- 产到 5 个 → 变成 L3 大屋。
- 只看这座屋的人，不要全图一满就集体升级。
- 升 mesh 时垫子跟着变大，门前缝还在。

### 屋顶产速

- 有人住：屋顶挂一个小图标（低多边形牌子即可），能看出正在产、产得快还是慢。
- 空屋或人满停产：图标不显示。
- 只要己方屋。不要字说明书，不要贴图。

### 不要做（这一刀）

- 不要开战、不要做法术。
- 不要重做点地走、寻路（已过）。
- 不要堆木头跳级。
- 不要上贴图、不要把人放大。

### 验收（各拍一张，传到设计师）

1. 一座空 L1：门口没人往外冒，屋顶没有产速图标。屋宇 1。
2. 选一个勇士点这座屋：人走到门边住进去，屋顶出现产速图标。
3. 等一会：门口走出一个新勇士，房子还是 L1，屋顶图标还在。
4. 再等到升 L2：房子变成中屋，屋顶图标还在。不要一次跳到 L3。

## 不要做

- 不要做法术、不要改已过的神迹。
- 不要热键。不要默认左键抬地。
- 不要上贴图。不要把人放大。
