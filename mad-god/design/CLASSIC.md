# 神也疯狂 · 开天辟地锁定

唯一参照：Bullfrog，《Populous: The Beginning》（《上帝也疯狂 3：开天辟地》，1998）。
3D 部落、祭司下场带着人打天下。**不要 1989 第一代。**

外形看 `art-direction/SPEC.md`。Object 看 `OBJECT.md`。

## 你是祭司，不是天上的手

玩家控制场上的 **祭司（Shaman）**。她施法、带队、死了回再生点。
人选人、下命令、派人去训练营。1989 那套「不点选、只铲地」作废。

## 单位（这些都要有）

| kind | 中文 | 怎么来 | 干什么 |
|---|---|---|---|
| shaman | 祭司 | 每队一个。死了在再生点复活 | 唯一施法者 |
| walker | 勇士 | 房子出人，或转化野人 | 砍树、盖房、进训练营 |
| warrior | 武士 | 武士训练营 | 近战 |
| preacher | 传教士 | 神庙。**不能删** | 近距离把敌人说成自己人（说不动敌方传教士和祭司） |
| firewarrior | 火战士 | 火战士训练营。**不能删** | 远程火球。角盔。近战很脆 |
| spy | 间谍 | 间谍训练营。**不能删** | 换成敌方颜色，混进去烧房子 |
| wildman | 野人 | 地图上的中立 | 祭司用转化术收成勇士 |

**没有牛头人。** 开天辟地里带角的是火战士。编制用 `firewarrior`。
没有国王，没有骑士英雄职业。

克制（先记着，战斗系统那刀再做）：传教士克武士，武士克火战士，火战士克传教士。

## 建筑

勇士砍树盖。房子要贴着再生点或已有建筑往外长（岗哨除外）。

- 茅屋：空 L1 用木头盖出来；有人住进去才慢慢产人，产到数量才升中、升大。不要堆木头跳级。
- 武士训练营
- 神庙（出传教士）
- 火战士训练营
- 间谍训练营
- 哨塔：塞一个人，射程变远。火战士、祭司尤其爽
- 岗哨：火把堆，绕圈巡逻
- 再生点：祭司复活
- 船厂 / 热气球（后做）

## 交互（开天辟地，不是 1989）

- 点选人、框选、下命令（去盖、去训练、去打、去站岗）。
- 祭司单独走，法术从她身上放，不是从天上点格子。
- 抬地 / 造桥 / 铲平是法术，不是上帝刷子。
- 征召 = 把勇士送进对应训练营，不是点一下变兵。

Object 这一刀先把人、房、地形的 Class 做对。训练和经济先能编过，规则后做。

## 神迹（祭司施放）

转化、闪电/冲击、地震、沼泽、火山、隐身、造桥、末日……数字后写。
这一刀不要重做特效。

## 和 Object 的关系

地仍然按 `OBJECT.md` 做高度场，不要柱体。
Unit 必须能表达上面七种 kind（野人算一种）。
Building 带 yaw，训练营和房子是不同 mesh。
