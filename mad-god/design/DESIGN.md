# 神也疯狂 · 设计总稿

给 3D 用。只参照《上帝也疯狂 3：开天辟地》，见 `CLASSIC.md`。外形 `SPEC.md`，体量 `SCALE.md`，顺序 `ROADMAP.md`。1989 第一代作废。

一句话：人口把地形变成神力，神力再把地形变成武器。

## 生产（机制第 1 刀，见 `PRODUCTION.md`）

核心循环：砍树 → 盖房 / 升级 → 进人 → 进训练营变兵 → 更多神力。
木头、训练营走进去才变兵，这一刀就要有。不要即时变身。

### 神力

- 上限和回复继续跟房子等级 + 人口走。
- 调到：开局能连续抬几格；要放地震 / 火山，必须先养出一镇子。
- 经济就是攻击力，不要另做科技树。

### 验收

- 只铺 3×3 台：人慢慢涨，很快顶帽。
- 把几座抬成 5×5 / 7×7：帽打开，人明显变快，法力条跟着长。
- 掀屋：帽立刻下降，多余的人不会被杀掉，只是不再补员。

## 魔法规则（机制第 2 刀，生产过关后才做）

先改数字和条件，不改特效。

| 神迹 | 消耗 | 解锁（manaCap） | 规则 |
|---|---|---|---|
| 抬 / 降 | 7 / 5 | 0 | 只改一格。降会检查掀屋。 |
| 闪电 | 20 | 0 | 点杀。优先打落点单位，溅射房子。 |
| 地震 | 50 | 120 | 半径 3，打乱高程，毁屋，淹低处。 |
| 沼泽 | 36 | 140 | 半径 2 的即死区，限时，吞人后可消失。 |
| 火山 | 80 | 160 | 隆起 + 岩浆，焦土一段时间不能盖房。 |
| 末日 | 100 | 200 | 「明显更多」= 己方 ≥ 对方+6 且 ≥ 对方×1.25。放了之后不能再抬地或施法，全民向中心对撞，打到一方灭。 |

- 解锁看上限，不看当前法力。
- 先不做人烟触及范围（全图可抬）。要加，单独立一刀。
- 红方 AI 用同一张表，不许开挂免费施法。

## 魔法视觉和判定（机制第 3 刀，规则过关后才做）

设计师已放行。现有特效能用的留着，缺的补上。

- 闪电：天顶到落点 4–6 段折线 + 细盒，短震约 0.18。点击格中心 1.2 格圆内所有单位脚底即死，落点房子溅射 -18。
- 地震：震屏约 0.65，约 0.7 秒柱体错层，屋毁时碎块下落约 0.6 秒。
- 沼泽：暗绿半透明盖（约 `#2a3f24`，不透明 0.55，略大于格 ~0.98），踩上即死，跟现有 `swamp[]` 走。
- 火山：先抬再铺熔岩，emissive 橙脉动，峰顶短喷约 0.5 秒；禁建看 `lava[]` 计时。
- 末日：全图横幅「末日决战 · 神迹封闭」，磁铁收束到岛心，不再收鼠标施法（primary / secondary / setTool 直接返回）。

## 完成标准

- 一座房子一块台，人不穿墙。
- 生产让「铺平地」变成唯一的膨胀手段。
