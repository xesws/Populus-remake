# 神也疯狂 · 生产（开天辟地）

Object 过了。这一刀只做生产和建造循环。不打、不法、不补特效。

参照《开天辟地》：勇士砍树 → 选中的人去盖 L1 → 住人后才产人、才升 2 / 3 → 进训练营变兵。
升级和住人看 `HOUSE.md`，不要再按堆木头跳级。

鼠标怎么点看 `INTERACT.md`。这一刀必须接上选人和建造预览。

## 树和木头

- 岛上散一些树（简单三块盒子：褐杆 + 两片绿冠）。可砍。
- 勇士走到树边，约 1.2 秒砍倒，背上 1 木头。树位空一段时间再长（约 25 秒）。
- 一次只背 1。背着木头只送给**未完成的 L1 茅屋或训练营工地**。不要送给已建成的屋去「升级」。

## 茅屋

- 点茅屋图标出现 3D 预览，左键点地才开工（见 INTERACT.md）。垫子可斜。
- **木头只够盖空的 L1。** L1 要 2 木头，mesh 到位就是一座空屋。
- **禁止堆木头升 2 / 3。** 升 2、升 3 必须有人住进去、自然产人到数量，见 `HOUSE.md`（住人那刀还没开，现在先停在 L1）。
- 人口帽以后跟等级走：L1=2，L2=5，L3=8。祭司、所有兵都占帽。
- 空屋不产人。住人、产速、升级那刀再开。
- 掀垫或拆屋：帽立刻降，人不杀。

## 训练营（必须排队走进去才变兵）

点征召 = 派**选中的**勇士走到对应营**门口排队**，同时只训 1 人、约 4 秒，出来变成那种人。不许自动抓全图最近的人。详规 `TRAIN.md`。

| 建筑 | 出兵 |
|---|---|
| warriorHut | warrior |
| temple | preacher |
| fireHut | firewarrior |
| spyHut | spy |

- 没有对应建筑就提示「先盖训练营」，不要点一下原地变身。
- 没选中的人一律继续原来的活（砍树、送木头）。禁止全员停工。
- 开局再生点旁给两座茅屋垫。训练营要勇士自己盖（4 木头）。
- 哨塔、船、气球这一刀不做。

## 再生点和野人

- 每队一个 rebirth。祭司死了在这里出（先留接口，战斗后做）。
- 地图上留几个 wildman。转化术后做；这一刀野人先站着。

## 神力

- 上限和回复跟茅屋等级 + 人口走。先别改法术表。

## 不要做

- 不要开战、不要补神迹演出。
- 不要把征召做成即时变身。
- 不要上贴图，不要把人放大。

## 验收

1. 勇士能砍树、把木头扛到 **L1 工地**，盖出空屋。不要再堆到 L3。
2. 拆屋只降帽，人不杀。
3. 先框选几个人，再点训练：只有圈里的勇士去营门口排队，圈外继续砍树。没选人点征召会提示「先选人」。
4. 队站住不乱跑。营顶有己方训练进度条。同时只训 1 人。

## v0.11 起：人口上限、生产速率与进度条

盖过上面「人口先不定上限」的旧写法，v0.11 起生产闭环完整：

- **人口上限**：`houseMaxPop` = L1: 2 / L2: 5 / L3: 10（`types.ts`）。`occupy` 拒超额；全局 `popCap` = 各屋上限之和。
- **生产速率**：`houseBaseRate(level)`（0.10 / 0.18 / 0.28）× `(1 + 0.12 × (dwell − 1))`——进驻村民越多生产越快；满员（dwell = cap）或人口到全局上限时停产。
- **进度条**：蓝方「有人住且未满员」的茅屋头顶显示绿色生产进度条（`render.ts syncProdBars`，仿训练条），数据源 `b.prod`（天然 [0,1)，每出生归零）。
- **名额释放（bug 修复）**：住户死亡在 `cull` 里释放 `dwell −1`；房屋被毁时住户迁出（`homeId` 清零、安置在原屋旁），不再出现「名额被尸体占死 / 居民随屋蒸发」。
- 升级规则不变：L1 born≥2 → L2，L2 born≥5 → L3（自动）。

## v0.11a 修复：升级占地恒定，只许长高

旧版 L2/L3 会把 pad 扩到 4.4/6.4 并重建更大的模型——升级瞬间把邻居房屋挤掉。现改为：

- `HOUSE_PAD / HOUSE_WALL / HOUSE_ROOF` 各级恒定为 L1 尺寸（pad 2.6），`padSize()` 不再随等级增长。
- 升级只改高度：L2 石屋（高 ~1.9）、L3 城堡（高 ~2.3）均与 L1 同占地；骨架模型同理。
- `world.houseLevelAt` 相应简化：恒定 pad 就绪即判可升 L3，地形只决定「可住 / 不可住」。
- 回归：`produce-check · testUpgradeKeepsFootprint`（两屋同升 L3 后 pad 不重叠且存活）。
